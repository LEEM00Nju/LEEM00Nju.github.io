# 사이버 보안 학습 및 워게임 문제 풀이 정리

## 1. Web 기초 개념 및 컴퓨터 과학 기초

### 웹(Web) 기초 개념
* **Web**: 현대 정보 통신을 대표하는 통신 수단 중 하나. 인터넷이라는 통신망을 활용하여 구현된 전 지구적 정보 공간을 의미하며, 웹으로 연결된 사람들 사이에 형성되는 정보의 흐름이 거미줄 같아 '웹'이라고 명명됨.
* **HTTP**: 인터넷을 기반으로 구현된 서비스 중 HTTP를 이용해 정보를 공유하는 서비스.
* **웹 서버 (Web Server)**: 정보 제공 주체.
* **웹 클라이언트 (Web Client)**: 정보를 받는 이용자.
* **프론트엔드 (Frontend)**: 이용자의 요청을 받는 부분. 이용자에게 직접 보여지는 부분으로, 페이지에 담기는 글, 배경 색상, 글자 색, 모양, 이미지 투명도 등 '웹 리소스'로 구성됨.
* **백엔드 (Backend)**: 요청을 처리하는 부분.

### 웹 리소스 (Web Resource)
웹에 갖춰진 정보 자산.
* **URL**: 모든 웹 리소스가 가지는 고유의 식별자. 
  * 예: `http://주소1/주소2` (주소1에 존재하는 주소2 경로의 리소스를 가져오라는 의미)
* **HTML**: 웹 문서의 뼈와 살 담당.
* **CSS**: 웹 문서의 생김새 지정.
* **JavaScript**: 웹 문서의 동작 정의 (어떻게 반응할지, 어디로 전송할지 등).

### 웹 클라이언트와 서버의 통신 과정
1. 브라우저를 이용해 웹 서버에 접속.
2. 브라우저는 이용자 요청을 해석하여, HTTP 형식으로 웹 서버에 리소스 요청.
3. 웹 서버는 HTTP로 전달된 이용자의 요청을 해석.
4. 해석한 이용자의 요청에 따라 적절한 동작 수행 (상황에 따라 탐색하거나 내부 연산 처리 등).
5. 이용자에게 전달할 리소스를 HTTP 형식으로 응답.
6. 브라우저는 서버에게 응답받은 웹 리소스(HTML, CSS, JS 등)를 시각화하여 출력.

### 컴퓨터 과학 기초
* **진법**: 임의의 숫자 또는 문자를 사용하여 수를 표현하는 체계(10진법, 2진법, 16진법, 8진법 등). 컴퓨터에서는 주로 2진법과 16진법을 사용.
* **바이트 오더링 (Byte Ordering)**: 바이트가 메모리에 저장되는 방식.
* **비트 연산**: 비트 단위로 수행하는 연산.
* **인코딩 (Encoding)**: 데이터를 특정한 형식으로 변환하는 것 (아스키코드, 유니코드, URL 인코딩, Base64 인코딩 등).
* **운영체제 (OS)**: 사용자 및 응용 프로그램과 하드웨어 사이에서 중재자 역할을 하는 소프트웨어. 하드웨어를 관리하고 사용자에게 편리함을 제공.

## 2. 워게임 문제 풀이 정리

### [Web] devtools-sources
* **풀이 과정**: 
  문제 설명에 "개발자 도구의 Source 탭 기능을 활용하세요"라는 힌트가 주어짐. 플래그 형식이 `DH`로 시작하므로, 개발자 도구(F12)를 열고 파일 전체 탐색 도구를 실행하여 `DH`라는 키워드를 검색해 플래그를 획득함.

### [Web] Cookie
* **풀이 과정**: 
  1. 주어진 파일의 코드를 분석하여 `guest`와 `admin` 유저네임이 존재함을 확인.
  2. 관리자 계정인지 확인하기 위해 루트 경로(`/`)를 입력해 보았으나 처음에는 플래그가 뜨지 않음.
  3. 개발자 도구(F12)를 켜서 `Application` -> `Cookies` 탭으로 이동.
  4. `name`이 `guest`로 되어 있는 `value` 값을 확인하고, 이를 `admin`으로 변경.
  5. 페이지를 새로고침하여 성공적으로 플래그를 획득함.

### [Web] session-basic
* **풀이 과정**:
  1. 파일 코드를 읽고 `/admin` 라우트 발견.
  2. 해당 라우트로 접속하니 `session_storage`에 있는 정보를 볼 수 있었음 (내부 정보가 주석 처리되어 있어 인증 없이 확인 가능).
  3. `admin`에 해당하는 세션 값을 복사.
  4. 개발자 도구(F12)의 `Application` -> `Cookies` 탭으로 이동하여 `name`에 `sessionid`를, `value`에 복사한 세션 아이디를 입력.
  5. 페이지를 새로고침하여 플래그를 획득함.

### [Web] Flying chars
* **풀이 과정**: 
  1. 개발자 도구(F12)를 켜서 `Network` 탭으로 이동.
  2. 네트워크 통신 기록을 확인하여 순서대로 이미지와 함께 정리된 글자 사진들을 확인.
  3. 각 코드를 읽고 조건문을 확인한 뒤, 해당 글자들을 알맞게 입력하여 플래그를 획득함.

### [Web] simple-web-request
* **풀이 과정**:
  제공된 코드를 분석한 결과 다음과 같은 조건문을 확인함.
  `if prm1 == "pooost" and prm2 == "requeeest":`
  해당 조건에 맞춰 파라미터 값(`prm1`, `prm2`)을 올바른 요청 방식으로 전달하여 플래그를 획득함.
